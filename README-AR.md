# ورقة — المصدر الكامل

## محتويات المشروع
- public/: ملفات الموقع الأصلية القابلة للتعديل: HTML وCSS ووحدات JavaScript، والمكتبات المحلية وملفات الخطوط المساعدة والتراخيص.
- public/index.html: الصفحة الرئيسية.
- public/app.mjs وcore.mjs وdocuments.mjs: منطق الأدوات والتحويلات.
- public/vendor/: مكتبات PDF وZIP وعامل PDF والموارد التابعة لها وتراخيصها.
- public/ads.txt وملف تحقق Google: إعدادات الناشر والتحقق الحالية.

الموقع ثابت ولا يحتاج خادم تطبيقات أو قاعدة بيانات أو أمر build. ملفات public هي المصدر ونسخة النشر نفسها. لا يتضمن الأرشيف Git أو مفاتيح وصول أو بيانات استضافة Sites الداخلية أو نسخ ZIP المصدرة السابقة.

## النقل إلى استضافة أخرى
1. فك الضغط.
2. ارفع محتويات public إلى مجلد النشر في استضافتك. يجب أن يوجد index.html مباشرة في جذر النشر.
3. إذا كانت الاستضافة تسأل عن Publish directory، اختر public. اترك Build command فارغًا.
4. قبل النشر على عنوان مختلف: حدّث canonical في الصفحات التسع، وروابط sitemap.xml، وسطر Sitemap في robots.txt من العنوان الحالي https://guileless-mooncake-864279.netlify.app/ إلى عنوانك الجديد.
5. حافظ على مسارات vendor وملفات mjs؛ يجب أن تقدمها الاستضافة بنوع JavaScript صحيح، وأن تسمح بتحميل عامل PDF من نفس الموقع.
6. لا تضف تحويل كل المسارات إلى index.html؛ الروابط الحالية صفحات HTML مستقلة.

## تشغيل محلي
من داخل مجلد المشروع شغّل:
python -m http.server 8000 --directory public
ثم افتح http://localhost:8000 . لا تستخدم file:// لأن وحدات JavaScript وعامل PDF يحتاجان HTTP.

## حالة AdSense والخصوصية
كود AdSense ومعرف الناشر ca-pub-5086201923236113 موجودان داخل head في الصفحات التسع. وجود الكود لا يضمن قبول الموقع أو ظهور الإعلانات. عند تغيير العنوان أضف الموقع الجديد داخل حساب AdSense وتحقق منه حسب تعليمات Google، وحدّث Search Console. راجع إعداد إدارة موافقة الزوار حيث تتطلبه سياسات Google؛ هذا المشروع لا يحتوي منصة CMP مفعلة. النصوص وصفحة الخصوصية موجودة ضمن المصدر وقابلة للتعديل.

## حدود الأدوات
- صور إلى PDF وPDF إلى صور: معالجة محلية في المتصفح ضمن الحدود المعروضة في كل أداة.
- إزالة الخلفية: إزالة لون بسيط متصل بالحواف وممحاة يدوية، وليست إزالة بالذكاء الاصطناعي.
- DOCX إلى PDF: تنسيق مبسط، دون دعم DOC القديم. الصفحات الناتجة صور.
- PDF إلى Word: استخراج نص مع احتمال اختلاف الترتيب والتنسيق؛ الصفحات المصورة تدخل كصور. لا توجد خدمة OCR.

مكتبات التحويل محلية. كود إعلانات Google يتصل بخدمات Google؛ لا يرسل الموقع محتوى ملفات التحويل إلى AdSense.
